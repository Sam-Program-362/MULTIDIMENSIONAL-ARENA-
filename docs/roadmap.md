# Roadmap

- **Phase 0 — Project Foundation (complete)** — Documentation and repository safeguards established.
- **Phase 1 — Simulation Foundations (in progress)** — Phase 1a fighter creation/save-load, Phase 1b-i fixed-timestep arena movement, Phase 1b-ii deterministic combat basics, Phase 1b-ii.1 stamina and attack-movement tuning, and Phase 1c the first AI opponent (the "Rookie sparring opponent") are implemented. Stamina is a defensive resource: basic attacks are sustainable, while blocking and dodging spend the bar. The training arena now offers a Dummy/Opponent toggle: the passive stationary dummy, or a deterministic Rookie AI that approaches, attacks, sometimes blocks/dodges, and can defeat or be defeated. It does not include adaptive/learning AI, personalities, multiple opponents, powers, progression, or combat persistence.
